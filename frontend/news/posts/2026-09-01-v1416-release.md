## New: Full-Weapon MILP Optimizer

Instead of manually checking individual attachment slots one by one, the new **Weapon Optimizer** evaluates all possible mod combinations across the entire firearm simultaneously in milliseconds using high-performance Mixed Integer Linear Programming (MILP).

- **Multi-Objective Weighted Tuning** - Balance Ergonomics, Recoil Reduction, and Price using a responsive 2D Ternary Plot or discrete sliders. Built-in quick presets include *Recoil*, *Ergo*, *Balanced*, *Min. Operable*, *Performance*, *Recoil+*, and *Ergo+*.
- **EvoErgo Tangent-Sweep Mode** - Direct optimization for true in-game Evo-Ergo Delta (EED) via an adaptive tangent-sweep search against the non-linear ergonomics weight curve.
- **Deep Constraint System** - Enforce hard limits on Budget (₽), Minimum Ergonomics, Maximum Weight, Sighting Range, and MOA Accuracy Spread.
- **Dual-Input Magazine Capacity Tuning** - Set minimum magazine capacity using either step-snapping sliders or direct number inputs with automatic mutual synchronization.
- **Attachment Locking & Banning** - Force-include (+) or ban (−) specific mods from the solve directly within the Mod Filter or straight from the Solved Build Manifest table with instant re-optimization.
- **Base vs Preset Cost Intelligence** - The solver automatically checks whether building from a bare receiver or stripping an intact factory preset is cheaper overall.
- **One-Click Build Injection** - Click **"Use This Build"** to load the optimized build into your active workbench tab instantly.
